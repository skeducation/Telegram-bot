Admin account

Create or sign in to your Firebase email account. This page uses the existing Firebase project and does not change your database content.

Important: Creating an account does not automatically grant admin access. After account creation, copy the UID shown here. The app's ADMIN_UID must be updated to that UID by the Firebase project owner. If Realtime Database already has /admin/uid locked to another UID, the owner must update that lock too. Never publish this setup page as an open public admin-registration page.
